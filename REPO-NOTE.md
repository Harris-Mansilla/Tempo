# Tempo repository

This repository contains the Tempo/Stride academic execution planner app and its supporting source, tests, and build artifacts.

The repository is intentionally public so the source can be inspected. It is **not open source** and is not a gift of reuse rights. Copyright © 2026 Harris Mansilla. All rights reserved; see [`LICENSE`](LICENSE).

The seeded planner data contains course-schedule context. No passwords, access tokens, student ID, connected-mailbox contents, or other authentication secrets are included.
